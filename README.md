# Student Management System

Python aur SQLite se bana command-line app jo students ka record manage karta hai.

## Features
- Student add karna (naam, course, marks)
- Saare students dekhna
- Naam se search karna
- Marks update karna
- Student delete karna

## Kaise chalayein
1. Python install hona chahiye (SQLite Python ke saath aata hai)
2. Terminal mein chalao: `python main.py`
3. `students.db` database file pehli baar chalne par khud ban jati hai

## Tech Used
- Python
- SQLite (sqlite3)
- CRUD operations
