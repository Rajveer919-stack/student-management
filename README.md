# Student Management System

A command-line app built with Python and SQLite to manage student records.

## Features
- Add a student (name, course, marks)
- View all students
- Search by name
- Update marks
- Delete a student

## How to run
1. Make sure Python is installed (SQLite comes with it)
2. Run: `python main.py`
3. The `students.db` file is created automatically on the first run

## Tech used
Python, SQLite (sqlite3), CRUD operations
